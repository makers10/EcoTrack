# 🌿 EcoTrack: Sustainability Redefined

EcoTrack is a premium, AI-powered sustainability platform designed to help users track, reduce, and visualize their carbon footprint through gamification and smart analytics.

## 🚀 Core Features & Architecture

### 1. Leaderboard (Implemented)
Global and community rankings based on carbon savings and eco-activity.
- Supports: Daily, Weekly, Monthly, and All-Time views.

### 2. Achievements & Badges (Implemented)
Earn badges for reaching sustainability milestones like "First Composted" or "Energy Saver".
- Automatic assignment based on activity thresholds.

### 3. Analytics Dashboard (Implemented)
Comprehensive visualization of carbon trends and personal impact scores.
- Includes carbon trend charts and activity breakdowns.

### 4. Eco-Challenges (Implemented)
Join community-wide challenges to earn XP and points.
- Features: Streak tracking and automated progress monitoring.

### 5. Community Groups (Implemented)
Join friends, schools, or workplaces to compete together as a team.

### 6. Social Sharing (Implemented)
Generate shareable Eco-Profiles and achievement cards to drive awareness.

## 🏗️ Future Roadmap (To Be Completed)

## 🛠️ Development Setup

1. **Backend**: NestJS with MongoDB (Mongoose)
2. **Frontend**: Vite + React + Tailwind CSS v4 + Framer Motion
3. **AI**: OpenAI GPT-4 for Personalized Eco-Advice
